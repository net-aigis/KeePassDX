# NetAigis KeySafe — attribution

NetAigis KeySafe is a modified fork of KeePassDX, by Jeremy Jamet / Kunzisoft
and other contributors. Original source-level copyright and license headers
are preserved. The original project can be found at:
https://github.com/Kunzisoft/KeePassDX

Original source license: GPL-3.0-or-later; see top-level LICENSE and LICENSES.
The NetAigis modifications include native HTTPS-coordinated KDBX access, related
security changes, and independent application identifiers/branding.

NetAigis KeySafe is **not an official KeePassDX application** and is not endorsed
by the upstream maintainers. Internal Java/Kotlin package names and some class
names are retained for binary/source compatibility and attribution, not branding.

The implementation must continue to provide Corresponding Source under GPL when
binaries are conveyed.
